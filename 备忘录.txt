WMS 项目开发规范 (V2.1 - UTC 修正版 & 安全标准)
1. 核心技术栈 (严格遵守) 🛠️
开发语言: Java 17 (LTS)。请合理使用 Record、Switch 表达式等新特性。

核心框架: Spring Boot 3.2.x。

构建工具: Maven。

数据库: PostgreSQL 16+。

ORM 框架: Spring Data JPA (Hibernate 实现)。禁止使用 MyBatis。

工具库: Lombok (简化代码), Spring Validation (参数校验)。

2. 架构与结构 🏗️
分层架构: controller -> service -> repository -> entity。

DTO 规范: 输入输出必须使用独立的 DTO (dto 包)，严禁在 API 层面直接暴露 Entity 实体类。

配置格式: 统一使用 YAML (application.yml)。

3. 🌍 时区与国际化 (核心红线)
参考: 隐式 UTC 架构决策

后端时区: 严格锁定为 UTC。

Java 环境: 启动类 @PostConstruct 中必须包含 TimeZone.setDefault(TimeZone.getTimeZone("UTC"))。

数据库连接: URL 必须包含 ?serverTimezone=UTC。

数据库存储: PostgreSQL 数据库默认时区必须设置为 UTC。

日期时间类型:

✅ 必须使用: java.time.LocalDateTime。

原因: 由于 JVM 已强制 UTC，LocalDateTime 即代表标准 UTC 时间，且能避免 Hibernate 映射 OffsetDateTime 时的驱动兼容性问题。

❌ 严禁使用: java.time.OffsetDateTime (会导致 Hibernate 映射报错), java.util.Date, java.sql.Timestamp。

语言规范:

代码注释: 必须全英文 (English ONLY)。(为了支持英国技术团队阅读)。

异常信息: 使用 错误码/Key (例如 STOCK_INSUFFICIENT)，禁止硬编码中文或英文字符串。前端将根据 Key 进行国际化翻译。

字符编码: 数据库和 API 必须支持 UTF-8。

4. 🔐 安全规范 (Security Layer)
认证机制: Spring Security + JWT (Stateless 无状态认证)。

密码存储: 必须使用 BCryptPasswordEncoder 加密存储，严禁明文存储密码。

权限控制:

/api/auth/** -> 允许匿名访问 (permitAll)。

/api/** (业务接口) -> 必须携带有效 Token。

5. 代码编写规范 📝
Repository 层: 优先使用 JPQL 或方法命名规则查询。

Service 层:

涉及状态修改的操作必须加 @Transactional。

库存核心逻辑: 任何库存变动，必须在 StockTransaction 表中记录 quantityBefore (变动前) 和 quantityAfter (变动后) 用于审计。

并发控制: 实体类使用 @Version (乐观锁)，Service 层使用 @Retryable 处理并发冲突。

6. 配置文件模板 (参考)
YAML

spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/wms_db?serverTimezone=UTC
    username: ${DB_USERNAME}
    password: ${DB_PASSWORD}
  jackson:
    time-zone: UTC
    date-format: yyyy-MM-dd HH:mm:ss
