# ORDERING 采购单再次编辑验收

## 已实现范围

- 仅 `ORDERING` 状态显示“编辑并保存”入口。
- 可修改供应商、预计到货日、整单备注，以及商品明细的数量、采购成本、生产日期、有效期、供应商批次码和备注。
- 采购单号、状态、创建操作人、实收数量、批次和库存均不由编辑接口修改。
- 保存使用采购单 `version` 做乐观并发控制；旧版本提交返回 `409 PO_EDIT_CONFLICT`，避免覆盖他人的新修改。
- 编辑动作追加到采购单审计日志，操作人从当前认证身份解析，不接受前端伪造。
- 回退到 `ORDERING` 且已有批次历史的明细，不允许更换商品、修改订购数量或删除；日期、成本和备注仍可调整。

## 接口契约

- `PUT /api/purchase-orders/{id}`
- 请求：`UpdatePurchaseOrderRequest`
- 响应：`PurchaseOrderResponse`，包含最新 `version`
- 权限：`purchase:create` 或 `SUPER_ADMIN`
