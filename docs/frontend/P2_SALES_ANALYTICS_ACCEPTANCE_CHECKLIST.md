## 验收步骤

### 1. 菜单与权限

- 左侧出现“经营分析”手风琴菜单，包含“销售概览”和“客户采购分析”。
- `SUPER_ADMIN`、`GENERAL_MANAGER` 可以进入；销售员及仓库角色默认不可见、不可访问。

### 2. 销售概览

- 打开 `/#/analytics/sales`，页面成功加载且无“请求失败”。
- 切换近 30/90/180 天，开始和结束日期同步变化。
- 销售额、有效订单、平均客单价、已发货、趋势和每日明细使用同一日期范围。
- 驳回、取消、作废订单不计入有效销售额，但在流程分布中单独显示。
- 查询范围超过 366 天时，后端应返回 `400`，不执行无边界统计。
- 页面明确提示数据来自夜间快照，并显示最近刷新时间。

### 3. 客户采购分析

- 打开 `/#/analytics/customers`，显示客户采购排名和总客户数。
- 关键词可按客户名称或编码筛选；客户类型与来源筛选可以组合使用。
- 点击“查看”打开右侧抽屉，显示客户累计订单、累计销售额、平均客单价和平均复购间隔。
- “常购商品”按该客户对 SKU 的累计采购金额排序，并显示 SKU 编码、累计数量、订单数与复购间隔。
- 已驳回、已取消、已作废订单不得进入客户事实统计。

### 4. 明确不在本批次的内容

- 利润、毛利率：暂不展示。需先建立销售成本、退货、税费、运费、汇率和成本法口径。
- Localization：语言、个人显示时区和公司业务时区继续按用户决定暂缓。
- RFM、流失评分、需求预测：属于未来 Python 洞察单元，不在 Java 事实层中伪造评分。
