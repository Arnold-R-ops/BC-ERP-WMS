## 4. 验收任务 A：出库作业

使用仓库员工或仓库管理员角色进入“出库作业”。

- [ ] 待拣货、拣货中、已完成三个队列可切换，搜索与筛选不会混入其他状态。
- [ ] 打开任务详情后，订单、商品、计划数量、批次、库位和追踪模式信息完整。
- [ ] `PRINTED_LABEL` 商品确认时要求匹配批次码；错误批次码应被拒绝。
- [ ] `LOCATION_VISUAL` 商品可使用库位与 SKU 完成反查确认，不要求输入批次码。
- [ ] 单任务确认后状态变为已完成，库存只扣对应任务数量。
- [ ] 批量确认包含无效任务时整批失败，其余待处理任务不得被部分扣减。

通过标准：任务状态、订单履约状态、批次库存与库存流水四处结果一致。

## 5. 验收任务 B：盘点作业

先用仓库管理员建单和启动，再切换仓库员工录入，最后用总经理复核。

- [ ] 可按仓库或库位创建盘点任务并启动。
- [ ] 仓库员工录入实盘数量时看不到系统账面快照，满足盲盘要求。
- [ ] 所有明细录入后可提交复核，未完成明细时不能提前提交。
- [ ] 总经理可查看账面数、实盘数和差异，并选择批准或退回。
- [ ] 仓库员工不能进入复核动作；总经理不能伪装成盘点员修改实盘数。
- [ ] 批准后库存变化和盘点差异一致，并留下操作人与时间记录。

通过标准：盲盘隔离有效，差异只在批准后落账，退回不会修改库存。

## 6. 验收任务 C：紧急库存校正

使用仓库管理员制单，使用总经理复核，再切回仓库管理员执行落账。

- [ ] 可针对已有批次创建校正，也可按业务规则创建未入账批次校正。
- [ ] 制单、提交、复核、批准和落账是独立动作，状态按顺序变化。
- [ ] 制单人不能审核自己的校正单。
- [ ] 总经理可批准或拒绝，但不能直接绕过落账动作修改库存。
- [ ] 仓库管理员只能对已批准记录执行落账，重复落账应被拒绝。
- [ ] 落账后批次库存、库位占用状态和库存流水保持一致。

通过标准：双人治理生效，任何失败动作不产生部分库存写入。
