## 📝 测试最佳实践

### 1. 测试命名规范
- 测试类：`{ClassName}Test` 或 `{ClassName}IntegrationTest`
- 测试方法：`test{MethodName}_{Scenario}_{ExpectedResult}`
- 示例：`testCreateCustomer_Success_AutoSetOwner()`

### 2. 测试结构（AAA 模式）
```java
@Test
void testMethod() {
    // Given - 准备测试数据
    CreateCustomerRequest request = ...;

    // When - 执行测试操作
    CustomerResponse response = customerService.createCustomer(request);

    // Then - 验证测试结果
    assertThat(response).isNotNull();
    assertThat(response.getCode()).isEqualTo("CUST001");
}
```

### 3. Mock 使用原则
- 单元测试：Mock 所有外部依赖
- 集成测试：使用真实数据库和服务
- 避免过度 Mock，保持测试真实性

### 4. 测试数据管理
- 使用 `@BeforeEach` 准备测试数据
- 使用 `@Transactional` 自动回滚
- 避免测试间数据污染

### 5. 断言使用
- 优先使用 AssertJ 的流式断言
- 提供清晰的错误消息
- 验证关键业务逻辑
