## 3. 本次关闭的问题

1. `AuthController` 的角色切换接口把 `Authorization` 当作框架必填请求头，缺少请求头时绕过既有鉴权映射并返回 500；现改为由业务鉴权统一返回 403。
2. 客户编号已经改为服务端自然数字生成，但 4 个后端测试仍提交并断言旧的自定义编号；测试已同步当前契约，并验证返回编号为数字。
3. `TenantDataPurgeIntegrationTest` 的直接 SQL 夹具没有补齐新增的 MFA 非空字段；现已补齐并通过真实集成测试。
4. 前端全量并行测试中，复杂 Ant Design 用例会越过默认 5 秒；统一测试超时调整为 10 秒，定向与全量均通过。
5. 权限申请验收脚本仅兼容 Windows PowerShell 5 的 HTTP 错误流读取；现同时兼容 PowerShell 7 的 `SkipHttpErrorCheck`，30 项真实 API 验收通过。
6. 客户表单新增税务／账户区域存在英文模式混入中文，并会保留上次打开的标签页；现改为完整 i18n 文案，每次打开回到详情页，并新增英文组件回归测试。
