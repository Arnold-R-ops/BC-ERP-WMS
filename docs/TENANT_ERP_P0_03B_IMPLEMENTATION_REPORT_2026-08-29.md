## 1. 本阶段交付结果

P0-03B 已在 P0-03A 的库存质量状态真相之上完成受控的人工隔离、召回冻结和恢复流程。质量冻结不会减少实存数量；整批或部分数量只会从 `AVAILABLE` 转为 `QUARANTINED` 或 `RECALL_HOLD`，因此继续计入在库，但不再参与销售预留、自动分配或出库。

本阶段没有提供允许客户端任意改写质量状态的通用接口。所有状态变更均由质量处理单驱动，使用登录用户作为操作人，并保留原因、数量、批次拆段、预留迁移、审批和幂等审计。

## 2. 部分冻结与库存真相

- 支持整批冻结和部分数量冻结。
- 部分冻结会在同一事务中拆出内部质量段，并保留原批次、内部批次、外部批次、生产日期和有效期追溯。
- 示例：实存 `100`、已预留 `30`，冻结 `10` 后，原可售段为实存 `90`、预留 `30`，冻结子段为实存 `10`、预留 `0`；总在库仍为 `100`。
- 新增 `qualityParentBatchId` 和 `qualitySegmentNo`，用于表达父子质量段关系；不生成新标签，也不要求重新贴标。
- 已完成的冻结单不可编辑。录入错误通过新的恢复动作纠正，保留原始审计链。

## 3. 销售预留影响与原子重分配

- 冻结优先使用未预留数量，不直接侵占销售承诺。
- 当冻结数量会影响预留时，先返回受影响的销售单、数量和可替代库存预览。
- 用户必须明确确认“重分配并冻结”；未确认时不写入任何库存、预留或任务数据。
- 只有尚未开始作业的 `PENDING` 出库任务可以迁移；进入拣货等后续状态后不再自动移动。
- 只有全部受影响预留都能迁移时才原子执行；替代库存不足时显示缺口，本次操作整体不落账。
- 重分配会同步调整库存预留记录和未开始的出库任务；需要拆分时保留原任务数量并创建对应的新任务段。

## 4. 恢复与可选审批

- 本阶段只允许把 `QUARANTINED` 和 `RECALL_HOLD` 恢复为 `AVAILABLE`。
- 恢复前校验库存段仍有效、数量大于零、未过期，且没有另一张待审核恢复申请。
- 默认策略为 `DIRECT_WITH_REASON`：具有恢复权限的用户填写标准原因后立即恢复。
- 租户管理员或被明确授予 `inventory_quality:policy` 的治理人员可以把策略切换为 `APPROVAL_REQUIRED`；该能力是可选配置，不与套餐强制绑定。
- 审批模式实行制审分离：申请人不能批准自己的申请；审核人可以批准或驳回，申请人可撤回待审核申请。
- `PENDING_INSPECTION` 留给 P0-03C；`DAMAGED`、`EXPIRED` 留给 P0-03D；`RETURN_INSPECTION` 留给 RMA 流程。

## 5. 权限、租户与仓库范围

新增五项独立权限：

- `inventory_quality:view`
- `inventory_quality:hold`
- `inventory_quality:release`
- `inventory_quality:review`
- `inventory_quality:policy`

迁移会为已有租户写入权限目录，但不会自动授予普通角色；新租户在创建时也会得到同样的五项可分配权限目录。普通用户默认没有这些权限，由租户管理员按需分配。后端继续执行租户隔离和仓库范围校验，仓库人员只能查询和处理其被授权仓库的数据。

## 6. 数据库迁移与审计

新增迁移 `V4_79__Inventory_Quality_Hold_And_Release.sql`：

- 为库存批次增加父质量段和段号字段。
- 新增质量处理单、处理明细和预留迁移审计表。
- 对动作类型、状态、冻结类型和数量建立数据库约束。
- 所有新表均启用并强制执行租户 RLS，使用复合租户外键防止跨租户引用。
- 冻结和恢复写入使用租户内幂等键；同一个请求不会重复拆段、迁移预留或执行状态变更。
- 审计保存登录操作人、时间、标准原因、补充说明、动作状态、处理数量、父子段关系和预留迁移结果。

迁移已在全新隔离 PostgreSQL 数据库中从基线实际执行至 V4.79；Flyway 校验、Hibernate `validate` 和应用启动均通过。验证数据库在导出 OpenAPI 后已删除，未改动现有开发数据库。

## 7. 接口与前端

- 租户端主页面的“库存治理”菜单新增“质量处理记录”，不是跳转到仓库独立端。
- 库存批次详情对有冻结权限的用户提供“冻结库存”入口，并把批次带入质量处理页面。
- 页面支持按内部批次、外部批次和 SKU 搜索，多仓库/多库位选择，整批或部分数量处理。
- 原因必须从冻结或恢复各自的标准原因清单中选择，客户端自由文本不能伪装成标准原因；补充说明仍为选填。
- 冻结提交前显示预留影响和替代库存；涉及预留迁移时使用二次明确确认。
- 页面提供冻结/恢复历史、处理详情、审核、驳回、撤回和租户管理员策略设置。
- 召回通知号和外部参考号为可选审计字段；附件本阶段不开发。
- OpenAPI 新增 `10` 条质量处理路径、`12` 个质量处理模型，并已重新生成 TypeScript 类型。
- 质量处理契约不包含供应商、采购价格、承运商或运单号，也没有暴露通用质量状态转换路径。
- 页面使用响应式表格、抽屉和弹窗，满足手机浏览器的基础操作；真实手机和手持终端验收仍按确认结果暂缓。
