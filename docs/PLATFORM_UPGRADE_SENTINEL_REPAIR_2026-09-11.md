### 合法审计动作和精确标识

审计动作固定使用已有合法 `WRITE`，不新增动作例外。每次完整验收生成一个 UUID v4：

- 用户使用 `p3-upgrade-<UUID>@fixture.invalid`，满足小写、长度及唯一邮箱约束。
- 审计使用 `resource_type=PLATFORM_USER`，`resource_id=p3-upgrade-<UUID>`，`detail_json` 保存同一 UUID 与测试用途。
- 旧会话使用该 UUID 作为 session_id，引用本次生成的用户及其 security_version。

哨兵用户禁用、不授予角色；不包含可登录密码、MFA 密钥或恢复码。字段读取按确切邮箱、审计资源标识、会话 UUID 定位，再核验外键确实指向本次用户。其他用户、其他审计记录或其他会话存在，不会被当作哨兵；不依赖全表只有一条。

### 明确事务

用户和审计在同一个 `BEGIN … COMMIT` 事务内创建；旧会话在 V4_89 后的另一个明确事务内创建。事务内有限时设置，使用返回的用户 ID、`INTO STRICT`、前置碰撞检查及写入后预期条数检查。不使用 upsert、删除重建或失败后跳过。

psql 保留 `ON_ERROR_STOP=1`；失败时不会继续执行 COMMIT，连接退出后由数据库回滚未提交事务。**本批验证的是生成 SQL 的事务结构和失败后停止编排，不是实际 PostgreSQL 回滚已经验收。** 真实回滚行为仍需下一次授权数据库批次验证。

### 升级前后校验

1. V4_88 后准备用户/审计，精确读取并要求各 1 条。
2. 升至 V4_89 后再次读取用户/审计，全部持久字段保持一致。
3. 准备旧会话，要求本次 UUID 恰好 1 条，用户和审计仍保持一致。
4. 升至 V4_90 后再次核验用户/审计，以及旧会话的全部原字段；仅允许新增 `browser_binding_hash` 且必须为 NULL。

使用结构化 JSON 比较而不是依赖字段序列化顺序。缺失、重复、错误关联、字段删除、值变化、浏览器绑定被回填均失败。用户认证字段不原样输出，改用其内容的 SHA-256 变化检测摘要，其余字段逐项保留比较。

### 阶段记录

新工具分别记录 `MIGRATION`、`SENTINEL_PREPARATION`、`SENTINEL_VERIFY` 的开始、成功或失败；数据库业务测试另有 `NOT_EXECUTED / RUNNING / PASSED / FAILED` 状态。

例如 V4_88 迁移完成后哨兵失败，会保留该迁移 `SUCCEEDED`，失败阶段准确记为 `sentinel-user-audit-prepare-v88`，数据库业务测试保持 `NOT_EXECUTED`。不会再把哨兵准备失败笼统记作迁移失败。**r3 原失败 JSON 的旧阶段记录未改写。**

工具同时增加冻结入口检查：执行文件必须位于对应封存源码路径且指纹一致；未重新绑定、封存的工作区工具拒绝借旧产物运行。

## 2. 核对的实际迁移契约

基于实际 B4_71、V4_72、V4_85–V4_90 源码；94 个迁移 SQL 原样保留，没有修改约束。

| 对象 | 本批核对 |
|---|---|
| platform_users | 14 个原始字段的类型、长度、非空和默认值；ID 序列/主键、唯一邮箱、小写规范、正 security_version、MFA 失败计数范围；可空 MFA 字段 |
| platform_audit_logs | 13 个字段的类型、长度、非空和默认值；ID 序列/主键、合法 WRITE 动作；操作者、目标用户、目标租户外键及可空性；现有不可修改审计触发器保留 |
| V4_89 platform_sessions | 8 个字段；UUID 主键、用户外键、正 security_version、时间字段非空、revoked_at 可空；last_activity ≥ started、absolute > started、最长 12 小时、idle 不超过 absolute 及 last_activity 后 30 分钟 |
| V4_90 新列 | browser_binding_hash 为可空 varchar(64)，NULL 或小写 64 位十六进制；不允许旧会话被回填或改写 |
| 中间迁移 | V4_72、V4_85–V4_88 未变更本哨兵三张表的字段/数据；如出现相关变更必须重新核对 |

契约检查包含字段/约束变异反例，例如移除非空、缩短长度、改变默认值、主键/唯一键/外键、修改时间边界、增加不兼容 CHECK、取消新列可空性等。它是受限的源码检查，**不是通用 SQL 解析器，也不能替代真实数据库执行**。
